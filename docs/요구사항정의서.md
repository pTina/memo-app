# 메모 앱 요구사항 정의서

직접 업로드한 폰트로 메모를 작성·수정·삭제하고, 선택한 글자만 꾸밀 수 있는 메모 서비스.
PC와 모바일 모두 사용 가능한 반응형 웹.

---

## 1. 기술 스택

| 구분 | 선택 |
|---|---|
| 프레임워크 | React + TypeScript |
| 스타일 | TailwindCSS (v4) |
| 디자인 시스템 | KRDS (https://github.com/KRDS-uiux/krds-uiux) |
| 서버 상태 | TanStack Query |
| 클라이언트 상태 | Zustand |
| 라우팅 | React Router |

**보조 라이브러리 (필요 시 최소로 도입)**

| 용도 | 후보 | 비고 |
|---|---|---|
| 리치 텍스트 에디터 | Tiptap | 선택 영역 스타일(글자색·형광펜·자간·행간)·링크·날짜 삽입 |
| 폰트 저장 | idb-keyval (IndexedDB) | 폰트 바이너리는 localStorage 용량(약 5MB) 초과 |
| 아이콘 | SVG → React 컴포넌트 (vite-plugin-svgr) | 이모지 사용 금지, 6장 아이콘 규칙 |
| 인증·저장 (2단계) | Firebase Auth (Google) · Firestore · Cloud Storage | 2장 참고 |
| 테스트 환경 (2단계) | Firebase Emulator Suite | 로그인 없는 어드민 테스트 모드 (2.3) |

## 2. 데이터 전략

별도 백엔드 서버나 Mock API(MSW)는 만들지 않는다.
저장소 어댑터 레이어를 두고, 구현만 교체하는 2단계 방식으로 진행한다.

### 2.1 단계 구성

**1단계 — 브라우저 로컬 (localStorage + IndexedDB)**
- 가입·설정·비용 없음, 데이터가 기기 밖으로 나가지 않음
- 메모·설정은 localStorage, 폰트 파일(Blob)은 IndexedDB
- 기기 간 동기화 불가

**2단계 — Firebase (Google 로그인 + Firestore + Cloud Storage)**
- 어댑터 파일 내부만 교체, 훅·컴포넌트 수정 없음
- **Google 로그인 필수**, 사용자별 데이터 격리
- 메모·설정은 Firestore, 폰트는 Cloud Storage
- PC ↔ 모바일 실시간 동기화
- 업로드 직전 비밀값 검사 (7장)
- **로컬 → 계정 이전:** 각 기기에서 첫 로그인 시 그 브라우저의 1단계 데이터를 계정으로 1회 이전

> 어댑터 함수는 1단계부터 전부 `async`로 작성한다. 동기로 만들면 2단계 전환 시 호출부를 모두 수정해야 한다.

**단계별 기능 차이**

| 기능 | 1단계 | 2단계 |
|---|---|---|
| 저장 위치 | 이 브라우저 | 계정 (Firebase) |
| 기기 간 이전 | — | 로그인만 하면 자동 |
| 로컬 → 계정 이전 | — | 기기별 첫 로그인 시 1회 |
| 휴지통 (30일) | 제공 | 제공 |
| 비밀값 검사 | — | 업로드 직전 |
| 로그인 | 없음 | 필수 (어드민 테스트 모드 예외) |

### 2.2 저장 위치

**1단계 저장 키**

| 저장소 | 키 | 값 |
|---|---|---|
| localStorage | `memo:memos` | Memo[] (휴지통 항목 포함) |
| localStorage | `memo:settings` | Settings |
| localStorage | `memo:version` | 마이그레이션 대비 버전 |
| localStorage | `memo:migratedTo` | 계정 이전 완료한 uid (2단계에서 기록) |
| IndexedDB | `memo-fonts` / `{fontId}` | FontFile (Blob + 메타) |

**2단계 Firestore 경로**

| 경로 | 값 |
|---|---|
| `users/{uid}/memos/{memoId}` | Memo |
| `users/{uid}/fonts/{fontId}` | 폰트 메타 (파일은 Storage `users/{uid}/fonts/{fontId}`) |
| `users/{uid}/settings/default` | Settings |

### 2.3 어드민 테스트 모드 (2단계)

운영에서는 로그인이 필수이고, 개발자가 로컬에서 테스트할 때만 로그인 없이 확인할 수 있게 한다.

| 항목 | 내용 |
|---|---|
| 실행 | `npm run dev:admin` (= `vite --mode admin`) |
| 환경 변수 | `.env.admin.local` — `VITE_AUTH_BYPASS=true`, `VITE_USE_EMULATOR=true` (커밋 금지) |
| 동작 | Firebase Emulator(Auth·Firestore·Storage)에 연결하고, 테스트 계정(`admin@test.local`)으로 자동 로그인 |
| 데이터 | Emulator 전용 가상 시드 데이터만 사용, 운영 Firestore에는 연결하지 않음 |
| 표시 | 화면 상단에 `테스트 모드` 배너 상시 노출 |
| 운영 차단 | 우회 코드는 `import.meta.env.DEV && VITE_AUTH_BYPASS` 조건 안에만 둬 운영 빌드에서 제거. `production` 빌드에 `VITE_AUTH_BYPASS`가 있으면 빌드 실패 처리 |
| 보안 규칙 | 운영 보안 규칙은 우회 없이 동일 (로그인 필수) |

## 3. 데이터 모델

메모 본문은 에디터 JSON으로 저장하고, 검색용 평문(`plainText`)을 함께 보관한다. 폰트는 메모마다 다르게 지정할 수 있다.

```ts
type Memo = {
  id: string;
  title: string;
  content: JSONContent;      // Tiptap 문서(JSON) — 스타일·링크 포함
  plainText: string;         // 검색용 평문
  fontId: string | null;     // null이면 기본 서체
  createdAt: string;         // ISO 8601
  updatedAt: string;
  deletedAt: string | null;  // 휴지통 이동 시각, null이면 정상 메모
};

type FontFile = {
  id: string;
  name: string;              // 표시 이름 (이름 바꾸기 가능)
  format: 'ttf' | 'otf' | 'woff' | 'woff2';
  size: number;              // bytes
  blob: Blob;                // 1단계 IndexedDB / 2단계 Cloud Storage
  createdAt: string;
};

type Settings = {
  theme: 'system' | 'light' | 'dark';
  defaultFontId: string | null;
  dateWithTime: boolean;     // 날짜 삽입 시 시간 포함
  sortBy: 'createdAt' | 'updatedAt';
  secretCheck: boolean;      // 비밀값 감지 (기본 true, 2단계부터 동작)
};
```

**휴지통 규칙**
- 삭제 시 `deletedAt`에 현재 시각 기록 (소프트 삭제), 목록·검색에서 제외
- 휴지통에서 복원(`deletedAt = null`) 또는 영구 삭제
- `deletedAt` 기준 30일이 지난 항목은 자동 영구 삭제
  - 1단계: 앱 실행 시 정리
  - 2단계: 앱 실행 시 정리 + Firestore TTL 정책 검토

**폰트 제약**

| 항목 | 값 | 근거 |
|---|---|---|
| 허용 형식 | `.ttf` `.otf` `.woff` `.woff2` | 현재 사이트와 동일 |
| 파일당 상한 | **20MB** | 한글 완성형 폰트는 보통 2~15MB, woff2는 1~5MB. 대부분을 수용하면서 비정상 파일은 차단 |
| 전체 상한 | **100MB / 최대 20개** | IndexedDB·Cloud Storage 사용량 관리 |
| 검증 | 확장자 + 파일 시그니처(매직 넘버) 확인 | 확장자만 바꾼 파일 차단 |

- 상한 초과 시 업로드 거부 + 사유 안내 (`woff2` 변환 권장 문구 포함)
- 폰트 삭제 시 해당 폰트를 쓰는 메모는 `fontId = null`(기본 서체)로 대체

## 4. 기능 범위 (MVP)

| 기능 | 내용 |
|---|---|
| 메모 목록 | 카드 목록, 정렬(최근 생성순·최근 수정순), 제목·본문 검색, 빈 상태 문구 |
| 메모 CRUD | `+ 새 메모` 생성, 자동 저장 수정, 삭제(휴지통으로 이동) |
| 일괄 삭제 | 체크박스 선택 후 `전체 선택 삭제` (휴지통으로 이동) |
| 스와이프 삭제 | 모바일에서 카드를 왼쪽으로 밀어 삭제 + `실행 취소` 토스트 |
| 휴지통 | 삭제 메모 목록, 복원, 영구 삭제, 비우기, 30일 후 자동 삭제 |
| 폰트 관리 | 드래그·클릭 업로드(네이티브 Drag & Drop), 이름 바꾸기, 삭제, 메모별 폰트 지정 |
| 선택 영역 꾸미기 | 툴바 — 글자색, 형광펜 4색, 자간(좁게·기본·넓게), 행간(좁게·기본·넓게) |
| 링크 | 선택 후 링크 버튼으로 URL 지정, URL 붙여넣기 시 자동 링크, 새 탭 열기 |
| 날짜 삽입 | 날짜 버튼으로 오늘 날짜 삽입, 설정에 따라 시간 포함 |
| Google 로그인 (2단계) | 로그인·로그아웃, 계정 표시 |
| 로컬 → 계정 이전 (2단계) | 기기별 첫 로그인 시 로컬 메모·폰트·설정을 계정으로 1회 이전 |
| 테마 | 시스템·라이트·다크, 헤더 테마 버튼으로 전환 |
| 생성·수정일 | 편집 화면에 요일·시간 포함 표시 |
| 사용법 | 6개 섹션 도움말 모달 (섹션 아이콘은 SVG) |

**로컬 → 계정 이전 (2단계)**
- 조건: 로그인 성공 + 로컬에 메모가 있음 + `memo:migratedTo`에 현재 uid 없음
- 다이얼로그: "이 브라우저의 메모 N개를 계정으로 옮길까요?" → `옮기기` / `나중에` / `옮기지 않기`
- 비밀값 검사 후 업로드, 폰트도 함께 이전 (용량 상한 적용)
- 동일 `id` 충돌 시 `덮어쓰기` / `사본으로 추가` / `건너뛰기` 선택
- 완료 후 `memo:migratedTo = uid` 기록, 로컬 데이터 삭제 여부를 사용자에게 확인
- 이전 실패 시 로컬 데이터는 그대로 유지하고 재시도 안내

**링크 제약**
- 현재는 링크 위 줄에 페이지 제목을 자동 추가하나, 외부 요청이 발생하므로 **기본 off**로 변경 (7장)
- `javascript:` `data:` 등 위험 스킴은 차단, `http(s)`만 허용, `rel="noopener noreferrer"`

## 6. 디자인 토큰

전역 CSS(`src/index.css`)는 Tailwind v4 `@theme`에 KRDS 토큰을 함께 불러와 사용한다.
테마는 `<html data-theme="light|dark">`로 전환하고, `system`은 `prefers-color-scheme`을 따라 `data-theme`을 지정한다.

### 6.1 토큰 값

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--font-sans` | IBM Plex Sans KR | 동일 | 기본 서체 (메모 기본 서체 포함) |
| `--color-ink` | `#2B2D31` | `#E6E7EA` | 본문 텍스트, 포커스 링 |
| `--color-muted` | `#5C6068` | `#A9ADB5` | 보조 텍스트 (날짜, 메타) |
| `--color-faint` | `#9CA1A9` | `#6E737C` | 흐린 텍스트 (placeholder, 비활성) |
| `--color-line` | `#EDEEF1` | `#2C2F35` | 기본 경계 |
| `--color-line-strong` | `#E0E2E7` | `#3A3E45` | 강한 경계 (카드, 입력칸) |

### 6.2 전역 CSS 추가분

```css
@import "tailwindcss";
@import "krds-uiux/resources/css/token/krds_tokens.css";

@custom-variant dark (&:where([data-theme="dark"], [data-theme="dark"] *));

@theme {
 --font-sans: "IBM Plex Sans KR", ui-sans-serif, system-ui, sans-serif;
```

### 6.3 사용 규칙

**에디터 꾸미기 프리셋**
- 글자색: `ink` · `muted` · `sunday`
- 형광펜 4색: `accent` · `work` · `personal` · `lemon`
- 형광펜·글자색은 토큰 이름으로 저장해 테마 전환 시 자동으로 라이트·다크 값이 적용되게 함

**색상 사용 원칙**
- 파스텔 색(`accent` `work` `personal` `lemon`)은 대비가 낮으므로 UI 글자색으로 쓰지 않는다
- `sunday`는 라이트 흰 배경에서 대비가 낮으므로 작은 UI 텍스트에 쓰지 않는다 (아이콘·사용자 글자색 프리셋만)
- 종이 결 질감은 `body::before` 노이즈 오버레이로 전 화면 공통 적용

**아이콘 규칙**
- 이모지 사용 금지, 모든 아이콘은 SVG 컴포넌트 (`shared/ui/icons`)
- `fill`/`stroke`는 `currentColor`, 기본 20px, 선 굵기 1.5px로 통일
- 아이콘 단독 버튼은 `aria-label` 필수, 텍스트와 함께 쓰는 장식 아이콘은 `aria-hidden="true"`
- 필요 아이콘: 검색, 휴지통, 복원, 설정, 도움말, 테마(해·달), 계정, 로그아웃, 추가, 뒤로, 더보기, 삭제, 글자색, 형광펜, 자간, 행간, 링크, 날짜, 업로드, 닫기, 체크, 경고
- Google 로그인 버튼은 Google 브랜드 가이드의 로고를 그대로 사용

**접근성**
- 포커스 링은 `var(--color-ink)` 2px, 라이트·다크 모두 표시
- 본문 대비 4.5:1 이상, 형광펜 위 글자도 대비 유지 (라이트·다크 각각)
- 툴바·모달 키보드 조작, 포커스 트랩, `Esc` 닫기
- 스와이프 삭제는 버튼 대체 수단 제공, 실행 취소 토스트는 `role="status"`
- `prefers-reduced-motion: reduce` 시 애니메이션·트랜지션 최소화 (전역 CSS 적용)

## 7. 개인정보보호 및 보안

원칙: 1단계에서는 메모가 기기 밖으로 나가지 않는다. 2단계에서 Firebase로 올라가는 데이터에는 API 키 같은 비밀값이 포함되지 않도록 업로드 직전에 검사한다.

### 7.1 공유 공간 유출 방지 (개발·배포)

GitHub Pages는 공개 저장소·공개 URL이므로, 저장소와 빌드 결과물에 중요 정보가 포함되지 않아야 한다.

| 항목 | 요구사항 |
|---|---|
| 비밀값 | API 키·토큰은 `.env.*.local`에만 두고 `.gitignore` 등록. `.env.example`에는 키 이름만 기재 |
| Firebase 설정 | 웹 설정값은 공개 전제이므로 보안은 **보안 규칙 + 인증**으로 담보. 서비스 계정 키는 절대 커밋하지 않음 |
| 승인 도메인 | Firebase Auth 승인 도메인은 `ptina.github.io`와 `localhost`만 등록 |
| 테스트 모드 차단 | 로그인 우회 코드는 운영 빌드에 포함되지 않음. `production` 빌드에 `VITE_AUTH_BYPASS`가 있으면 빌드 실패 (2.3) |
| 커밋 검사 | pre-commit 훅(gitleaks 등)으로 비밀값 패턴 커밋 차단, GitHub Secret scanning 활성화 |
| 샘플 데이터 | 시드·테스트·사용법 이미지에 실제 키·개인정보 사용 금지 (가상 데이터만) |
| 배포 범위 | `dist`만 배포. 소스맵은 프로덕션에서 비활성화 |
| 로그 | 메모 본문·제목을 `console`, 에러 리포트, 분석 도구로 전송하지 않음 |
| 외부 요청 | 분석·광고 스크립트 미사용. 폰트·라이브러리는 번들에 포함해 외부 호출 최소화 |

### 7.2 Firebase 업로드 비밀값 검사

| 항목 | 요구사항 |
|---|---|
| 검사 시점 | Firestore 쓰기 직전 (어댑터 레벨에서 수행해 우회 불가) — 일반 저장, 로컬 → 계정 이전 모두 포함 |
| 검사 대상 | 메모 제목 · 본문(`plainText`) |
| 감지 패턴 | 아래 표 |
| 감지 시 처리 | 업로드 보류 + 경고 다이얼로그: `마스킹 후 저장`(기본 선택) / `그대로 저장` / `취소` |
| 일괄 처리 | 로컬 → 계정 이전처럼 여러 건이면 감지된 메모 목록을 한 번에 보여주고 일괄 선택 |
| 마스킹 | 앞 4자만 남기고 나머지 `••••` 처리 (예: `AIza••••`) |
| 1단계 | 로컬 저장에는 검사하지 않음 (기기 밖으로 나가지 않음) |
| 검사 위치 | 브라우저 안에서만 수행, 검사 결과·원문을 외부로 전송하지 않음 |

**감지 패턴**

| 종류 | 정규식 (예시) |
|---|---|
| Google / Firebase API 키 | `AIza[0-9A-Za-z_\-]{35}` |
| GitHub 토큰 | `gh[pousr]_[0-9A-Za-z]{36,}` |
| OpenAI / Anthropic 키 | `sk-(ant-)?[0-9A-Za-z_\-]{20,}` |
| AWS 액세스 키 | `AKIA[0-9A-Z]{16}` |
| JWT | `eyJ[\w-]+\.[\w-]+\.[\w-]+` |
| 개인키 블록 | `-----BEGIN [A-Z ]*PRIVATE KEY-----` |
| `.env` 형식 할당 | `(API\|SECRET\|TOKEN\|PASSWORD\|KEY)\w*\s*[=:]\s*\S{8,}` (대소문자 무시) |

### 7.3 서비스 내 데이터 보호

| 항목 | 요구사항 |
|---|---|
| 링크 제목 자동 추가 | 외부 프록시로 URL이 전송되므로 기본 off |
| XSS 방지 | `dangerouslySetInnerHTML` 금지, 링크는 `http(s)`만, CSP 메타 태그 적용 |
| 데이터 삭제 | 설정에 `로컬 데이터 전체 삭제` 제공 (공용 PC 대비), 삭제 전 확인 |
| 로그아웃 (2단계) | 로그아웃 시 Query 캐시·Firestore 오프라인 캐시 초기화 |
| 안내 | 사용법에 저장 위치(1단계: 이 브라우저 / 2단계: 계정)와 공용 PC 사용 후 로그아웃·삭제 안내 |

### 7.4 2단계(Firebase) 추가 요구사항

- Google 로그인 필수, 비로그인 상태에서는 읽기·쓰기 불가 (어드민 테스트 모드는 Emulator 한정, 2.3)
- 보안 규칙: `users/{uid}/**`는 `request.auth.uid == uid`일 때만 허용
- 테스트 모드(전체 허용) 규칙으로 배포 금지, Emulator로 규칙 테스트 후 배포
- App Check 적용, Storage 규칙으로 폰트 용량(20MB)·형식 제한
- 공개 공유 링크 기능은 MVP 범위 밖

### 8.3 상태 관리

**TanStack Query — 저장소 상태**

| queryKey | 내용 |
|---|---|
| `['memos', { sortBy, q }]` | 메모 목록 (`deletedAt == null`, 정렬·검색) |
| `['memo', id]` | 메모 단건 |
| `['trash']` | 휴지통 목록 (`deletedAt != null`) |
| `['fonts']` | 폰트 목록 (메타) |
| `['settings']` | 설정 |
| `['auth']` | 로그인 사용자 (2단계) |

- 자동 저장·휴지통 이동·복원은 `onMutate` 낙관적 업데이트 + 실패 시 롤백

- 로그인·로그아웃 시 사용자 범위 쿼리 전체 무효화
- 폰트는 `useFontFace`에서 `FontFace` API로 등록, Blob URL은 언마운트 시 해제
